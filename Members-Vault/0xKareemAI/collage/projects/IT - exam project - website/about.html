Project Objectives

The main goal of this project is to showcase proficiency in front-end development technologies.

Technical Requirements Checklist

  1. Implement semantic HTML5 elements.
  2. Apply CSS using External, Internal, and Inline methods.
  3. Create a responsive and consistent layout across 3 pages.
  4. Develop a functional navigation bar.
  5. Add JavaScript-based form validation with specific constraints.

# IT Lab Exam Project 🚀

A professional, responsive, and validated multi-page website developed for the Internet Technologies Lab Exam.

## 📁 Project Structure

```text
IT-Exam-Project/
├── assets/
│   ├── css/
│   │   └── style.css       # Core design system
│   ├── js/
│   │   └── script.js      # Form validation logic
│   └── img/
│       └── theLogo.png     # University branding
├── docs/
│   ├── Lab Exam.pdf        # Original task requirements
│   └── requirements.md     # Detailed implementation summary
├── index.html              # Home page
├── about.html              # About & Schedule page
├── contact.html            # Contact & Validation page
└── README.md               # Project documentation
```

## ✨ Key Features

- **Professional Design**: Modern UI with a curated color palette (Midnight Blue, Crimson, Gold) and smooth typography (`Outfit` from Google Fonts).
- **Responsive Layout**: Fully responsive design that adapts to various screen sizes.
- **Form Validation**: custom JavaScript validation for the contact form, including university email domain checks (`@azhar.adu.eg`) and password length verification.
- **Semantic HTML5**: Proper use of semantic elements (`<header>`, `<nav>`, `<main>`, `<footer>`, `<section>`) for better accessibility and SEO.
- **Clean Codebase**: Organized folder structure following industry standards.

## 🛠️ Technologies Used

- **HTML5**: Structural markup.
- **CSS3**: Styling, including Flexbox, Gradients, and Transitions.
- **JavaScript**: Client-side logic and validation.

## 📜 Academic Integrity

This project was built to satisfy the requirements of the IT Lab Exam at Al-Azhar University.
